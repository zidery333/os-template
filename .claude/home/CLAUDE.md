# Home folder

Once copied out beside my OS folders, this folder looks after them. It sits
beside them, never above them, and holds no rules of its own — each folder
keeps its own.

`./home status`, `./home check`, `./home sync [name] [--apply]` and
`./home add <path> "what it's for"`. `README.md` explains each one.
`folders.tsv` is the list. `master/template/skills/` holds the skills every
folder shares.

Never write into another folder except through `./home sync <name> --apply`.
Never touch any folder's me/, notes/ or work/. Never delete. Never start a job
in another folder.
