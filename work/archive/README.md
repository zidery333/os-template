# work/archive/

Projects that are finished or dead. Same shape as an active one — the folder
just moved.

Put here by `/archive`. Nothing in here gets checked for going stale, because
going stale is the point.

**Why keep them.** The `decisions.md` file is the part that stays useful. A
year after a project ends you'll hit the same choice again, and the answer to
"we tried that, here's what happened" is sitting right here.

**When to actually delete one.** When you'd be happy never to see it again,
and you're sure nothing else points at it. Deleting is fine — this folder is
not a museum. Just do it on purpose rather than letting it rot.
