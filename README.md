# 🎯 Prompts

Writes a prompt for any AI — ChatGPT, Claude, Gemini, Midjourney, Veo, Kling — tests it when it can, and finds out why a prompt keeps giving bad answers and fixes it. Built from the official prompting guides.

An addon for [Zenith](https://github.com/zidery333/os-template/tree/os). Inside your Zenith folder, type:

```bash
./os addon prompts
```

`./os update` keeps it up to date. It only adds skills and helpers: nothing of yours is changed.
