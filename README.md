# Zenith

One folder for your work, notes and files. Any AI can run it.

**Start:** download this folder, open it in a terminal, and type `./os`.
Then open it in Claude Code, or any AI, and just talk. On a Mac, if it says
Python is missing, type `xcode-select --install` and try again.

**Get the newest version:** type `./os update` inside your folder. Your work
and notes are never touched. A skill you changed yourself is kept, and the new
one is put beside it for you to merge. Settings you changed keep your changes,
with any new ones added.

Broken thing or better idea? Type `./os snag --export` and send the
`template-feedback.md` it writes to **zidery333** on Discord.

This is the `os` branch. The `main` branch is the older me/ notes/ work/ layout.
