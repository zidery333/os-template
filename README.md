# 🔗 Subchat chain

Runs a big job as one main chat that hands each step to its own subchat, one after another, checks each one's work, then sends you one clean summary. For Claude Code in the Claude desktop app.

An addon for [Zenith](https://github.com/zidery333/os-template/tree/os). Inside your Zenith folder, type:

```bash
./os addon subchat-chain
```

`./os update` keeps it up to date. It only adds skills and helpers: nothing of yours is changed.
